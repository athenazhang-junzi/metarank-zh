# 部署概览

> 英文原文：[`doc/deploy/deployment-overview.md`](../../deploy/deployment-overview.md)

- [Standalone](standalone.md)：单机 JVM 或 Docker，适合本地测试与简单环境；
- [Docker](docker.md)：以官方容器镜像运行；
- Kubernetes：适合多实例生产部署，中文版本暂未翻译；
- Prometheus：导出 JVM 和应用指标，中文版本暂未翻译。

生产环境还应阅读[生产运行建议](../dev/production-recommendations.md)和[状态持久化](../configuration/persistence.md)。
