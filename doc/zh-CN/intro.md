# Metarank 是什么？

[Metarank](https://metarank.ai) 是一个开源排序服务，可用于构建个性化语义搜索、神经搜索和推荐系统。

如果希望尽快上手，可以阅读：

- [快速开始](quickstart/quickstart.md)：在已有搜索或推荐候选集上实现学习排序；
- [Cross-Encoder 搜索重排指南](../guide/search/cross-encoders.md)：使用大语言模型进行神经搜索重排，目前为英文；
- 协同过滤推荐指南：上游文档仍在完善中。

## 为什么使用 Metarank？

Metarank 可以在既有搜索和推荐系统之上加入用户行为信号：

- 将点击、购买等反馈纳入排序目标；
- 维护访客画像，让结果随用户行为实时变化；
- 以 Bi-Encoder 或 Cross-Encoder 方式使用语言模型理解查询语义；
- 计算 CTR、来源页、User-Agent、时间等常见排序信号；
- 从多种数据源接收用户行为事件。

项目方提供了关于延迟和水平扩展能力的性能说明。实际性能会受到候选集规模、特征数量、存储、模型和部署方式影响，使用前应在自己的数据与环境中测试。

## 可以构建什么？

- **语义搜索**：让 Elasticsearch、OpenSearch 等检索系统进一步理解查询含义；
- **推荐系统**：构建协同过滤、相似内容、热门内容和语义内容推荐；
- **学习排序**：在原搜索或推荐结果之上进行二次重排；
- **实时个性化**：根据用户近期行为更新排序特征和结果。

## 主要能力

| 能力 | 说明 |
|---|---|
| 热门推荐 | 根据交互趋势和时间衰减生成热门内容 |
| 相似内容 | 使用矩阵分解等方法生成相似物品推荐 |
| 二次重排 | 使用 LambdaMART 等模型重新排列候选集 |
| 自动特征工程 | 根据事件数据推断常见特征配置 |
| 模型重训练 | 从排序和交互事件中生成训练样本 |
| 多模型服务 | 通过不同模型名称提供多个排序版本 |

## 它不负责什么？

Metarank 的核心定位是排序服务，不等于完整的推荐产品平台。通常仍需要外部系统负责：

- 从全量内容库召回候选内容；
- 用户分桶和实验流量分配；
- SRM、样本量、显著性和长期效果分析；
- 内容审核、库存和强业务约束；
- 产品界面与最终业务决策。

## 基本数据流

```text
搜索或推荐系统产生候选集
          ↓
调用 /rank/<model> 请求重排
          ↓
Metarank 计算特征并返回新顺序
          ↓
应用展示结果
          ↓
向 /feedback 回传 ranking 与 interaction 事件
          ↓
Metarank 将曝光和交互关联为训练数据
          ↓
训练并加载新的排序模型
```
